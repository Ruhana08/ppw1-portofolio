## Daftar Praktikum

## Deskripsi Repositori
Repositori ini berisi kumpulan tugas dan proyek praktikum mata kuliah Pemrograman Web 1 (PPW1) dari Bab 1 hingga Bab 14. Proyek di dalamnya mencakup pengembangan web dasar menggunakan HTML, CSS, Bootstrap, PHP dasar, hingga operasi CRUD (Create, Read, Update, Delete) dengan database MySQL.

---

## Daftar Materi Bab

| Bab | Nama Folder / Materi | Deskripsi Singkat |
| :---: | :--- | :--- |
| 1 | `bab-1-pengenalan` | Pengenalan & Instalasi Tools (Tidak ada tugas) |
| 2 | `bab-2-dasar_html` | Dasar-dasar Tag HTML & Struktur Dokumen |
| 3 | `bab-3-link_inframe_tabel_semantic` | Implementasi Link, Iframe, Tabel, & Tag Semantic |
| 4 | `bab-4-form_and_graphic` | Pembuatan Form Input & Penanganan Grafis |
| 5 | `bab-5-stylesheet` | Pengenalan CSS Dasar & Pewarnaan Layout |
| 6 | `bab-6-web_responsif` | Desain Web Responsif dengan Media Queries |
| 7 | `bab-7-stylesheet_2` | CSS Lanjutan & Penataan Layout Kompleks |
| 8 | `bab-8-bootstrap5` | Desain Interface Cepat Menggunakan Framework Bootstrap 5 |
| 9 | `bab-9-design_website` | Pembuatan Proyek Desain Website Terintegrasi |
| 10 | `bab-10-javascript` | Pengenalan Logika Dasar JavaScript Client-Side |
| 11 | `bab-11-php` | Pengenalan Dasar Pemrograman Sisi Server dengan PHP |
| 12 | `bab-12-crud` | Koneksi Database & Operasi CRUD (Create, Read, Update, Delete) |
| 13 | `bab-13-php_lanjutan` | Pengembangan PHP Lanjutan & Penanganan Form |
| 14 | `bab-14-penutup` | Evaluasi & Dokumentasi Akhir Portofolio |
